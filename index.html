Machine Learning and Robotics

  • OpenVLA Experiments↗ gitlab.com/cogmod_mr/rlvla_mod Research code for OpenVLA LoRa training using RL, SFT, several experimental hybrid methods, including custom-made Real-to-Sim environment Based on the github.com/gen-robot/RL4VLA repository.
  • Maniskill Experiments↗ gitlab.com/cogmod_mr/maniskill_full_mod Research code for training small custom VLA models on Maniskill task suite using experimental IL and RL methods. Based on github.com/mani-skill/ManiSkill repository.
  • IsaacLab Experiments↗ gitlab.com/cogmod_mr/isaaclab_mod Research code for training small custom VLA models on IsaacLab framework using experimental IL and RL methods. Based on github.com/mani-skill/ManiSkill repository.
  • Cross-View Localization System↗ gitlab.com/dmitriypoyarkov/cross-view-localization ROS-based modular localization system for GPS-denied environments using satellite imagery as a global reference.
  • Visual Landmark Navigation System↗ gitlab.com/dmitriypoyarkov/path_finder ROS-based navigation system for a mobile robot operating without global localization.
