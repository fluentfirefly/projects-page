# Projects page

A small, dependency-free portfolio skeleton designed for GitHub Pages.

## Preview locally

Run a basic web server from the repository root:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Customize

- Replace the placeholder name, introduction, project text, and links in `index.html`.
- Update the colors and type scale near the top of `styles.css`.
- Replace the gradient project placeholders with images when ready.
- Change the description and page title in the `<head>` of `index.html`.

## Deploy

Push the `main` branch to GitHub, then configure GitHub Pages to deploy from the
repository root. See GitHub's Pages settings for custom-domain and HTTPS options.
